# job-board

## Project Context & Objectives

The Job Board aims to provide a simple platform where users can discover and interact with available job offers.

The platform supports three types of users:

* **Visitor:** Can browse, search, sort, filter, and view job offers.
* **Student (Apprenant):** Has all visitor permissions and can follow or unfollow offers.
* **Administrator:** Can create, update, and delete offers and associate technologies with them.

### Main Features — Sprint 1

*  **Offer Consultation:** View available job offers.
*  **Search:** Search for available offers.
*  **Sorting:** Sort job offers.
*  **Filtering:** Filter available offers.
*  **Offer Details:** View detailed information about an offer.
*  **Follow Offers:** Students can follow offers.
*  **Unfollow Offers:** Students can unfollow offers.
*  **Create Offers:** Administrators can create new offers.
*  **Update Offers:** Administrators can update existing offers.
*  **Delete Offers:** Administrators can delete offers.
*  **Technology Association:** Administrators can associate technologies with an offer.
