# Cahier des Charges Analysis

## 1. Project Overview

Job Board is a platform that allows users to consult and interact
with job offers.

## 2. Objectives

The main objectives of the project are:
- Allow users to view available job offers.
- Allow learners to search, sort, and filter offers.
- Allow learners to follow and unfollow offers.
- Allow administrators to manage job offers.
- Allow administrators to associate technologies with offers.

## 3. Users

### Apprenant
The learner can:
- View offers
- Search for offers
- Sort offers
- Filter offers
- Follow offers
- Unfollow offers
- View offer details

### Administrator
The administrator can:
- Create offers
- Update offers
- Delete offers
- Associate technologies with offers

## 4. Main Features

### Offer Consultation
Users can browse available job offers.

### Search and Filtering
Learners can search, sort, and filter job offers.

### Offer Interaction
Learners can follow or unfollow offers and view their details.

### Offer Management
Administrators can create, update, and delete offers.

### Technology Management
Administrators can associate technologies with job offers.
